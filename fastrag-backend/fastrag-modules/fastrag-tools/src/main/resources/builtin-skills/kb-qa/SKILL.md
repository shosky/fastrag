# 知识库问答技能

当用户提出需要**领域知识**的问题时，使用此技能从已配置的知识库中检索相关信息。核心原则：**先选库、再检索、后验证、再回答**。

## 编排流程

### 1. 知识库选择

- 如果用户未指定知识库，先用 `list_kbs` 列出可用的知识库
- 根据问题领域自动匹配合适的知识库
- 跨领域问题支持**多知识库联合检索**

### 2. 执行检索

使用 `query_kb` 工具，参数说明：

```json
{
  "kb_id": "产品知识库",
  "query": "产品的退款政策是什么",
  "top_k": 5,
  "mode": "hybrid"
}
```

- `kb_id`: 知识库名称或 ID
- `query`: 检索问句，建议用完整问题而非关键词
- `top_k`: 返回片段数，默认 5，复杂问题增至 10
- `mode`: 搜索模式推荐
  - `vector` — 语义搜索，适合开放性问答
  - `fulltext` — 关键词搜索，适合精确匹配（编号、条款）
  - `hybrid` — 混合搜索，大部分场景推荐

### 3. 结果验证

- 检查检索结果与问题的相关性，丢弃无关片段
- 多个片段矛盾时标注冲突，不强求统一
- 置信度低于阈值的片段注明"仅供参考"

### 4. 溯源回答

回答模板：

```
## 回答

[核心答案，基于知识库内容]

## 参考来源

- [文档名] 第 X 节："[引用原文片段]"
- [文档名] 第 Y 节："[引用原文片段]"
```

## 可用工具

- `list_kbs` — 列出用户可访问的知识库列表
- `query_kb` — 在指定知识库中执行语义/全文/混合检索

## 输出约束

- 每个结论必须绑定知识库来源引用
- 知识库没有相关信息时如实告知，不编造
- 涉及数字、政策、流程时直接引用原文
- 引用格式：`[文档名称] 第 X 节："原文片段"`
