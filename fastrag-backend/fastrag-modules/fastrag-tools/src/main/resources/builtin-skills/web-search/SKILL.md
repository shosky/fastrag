# 联网搜索技能

当用户的问题需要**实时或最新信息**（新闻、天气、股价、赛事、百科等）时，使用此技能组织整个检索与摘要过程。核心原则：**先计划、再检索、后综合**，避免盲目多次调用。

## 编排流程

### 1. 拆解查询意图

用户问题可能一次包含多个信息需求。先拆解为**可独立检索**的子问题，例如：

- 用户问"今天北京天气怎么样+最近有什么科技新闻" → 拆为 `[天气:北京, 科技新闻]`
- 每个子问题使用一次搜索工具，互不依赖的并行检索

### 2. 调用搜索工具

使用 `tavily_search` 工具，参数说明：

- `query`（必填）：精确的搜索关键词，尽量用原文核心词
- `search_depth`（可选）：`"basic"` 快速 / `"advanced"` 深度（复杂问题用 advanced）
- `max_results`（可选）：返回条数，默认 5，综合类问题可增至 10
- `include_domains` / `exclude_domains`（可选）：限定/排除来源域名
- `include_answer`（可选）：是否返回 LLM 生成的摘要

```json
{
  "query": "2026年北京最高气温",
  "search_depth": "basic",
  "max_results": 5
}
```

### 3. 交叉验证

- 对关键事实（数字、日期、人名）至少有 **2 个独立来源** 交叉印证
- 来源冲突时如实标注分歧，不强行统一
- 优先采信权威来源（政府网站 `.gov`、学术 `.edu`、一手报道）

### 4. 结构化输出

按以下模板组织最终输出：

```
## [主题]

**结论**：[一句话核心答案]

**关键信息**：
- [要点1]（来源：<cite>$URL</cite>）
- [要点2]（来源：<cite>$URL</cite>）

**时效性**：数据截至 [日期]

**注意**：[如有不确定性或冲突，在此标注]
```

## 可用工具

- `tavily_search` — 互联网搜索引擎，覆盖新闻、网页、百科

## 输出约束

- 必须附带来源链接（使用 `<cite>` 标签）
- 时效敏感数据标注截止时间
- 搜索不到权威来源时如实告知，不得编造
- 引用格式：`<cite source="$URL" type="url">引用文字</cite>`
