# 平台导航壳改造 — Frontend Spec

## 范围 {#scope}

本规格覆盖 FastRAG **平台壳**（CONTEXT.md「平台」条目，AppLayout 承载的功能路由整体）的导航层改造。侧边栏由现有「窄条 icon rail + 二级菜单面板」双列形态（`Sidebar.vue:363-511`）改造为**单列宽侧栏**（CONTEXT.md「单列宽侧栏」条目，分组标题 + 菜单项直排）。菜单按**导航四段**（CONTEXT.md「导航四段」条目）重组：对话 / 构建 / 资源 / 管理，对标腾讯云 ADP「使用智能体/构建智能体/资源中心/平台管理」动线分组（2026-10-26 截图分析）。

同时覆盖五项：主页顶置（四段之上的独立入口）；**资源中心**段汇聚（CONTEXT.md「资源中心」条目，九项，其中模型管理自「管理>开放平台」移入、提示词模板为新挂载菜单）；管理段四处运营页聚拢为「数据分析」（修订 #14 收进下拉后，#15 改回**侧边栏第四段**）；管理段 12 项收进右上角用户下拉「管理」分组（修订 #15，见「元素与交互」）；修订 #18：知识库分类收敛进知识库页左侧分类面板（首个页面级例外，限知识库列表页）；顶栏通知铃铛接线既有通知中心（新路由 `/notification`，CONTEXT.md「通知中心」条目）；侧栏用户入口扩容与 `menu-perm-tree.ts` 分组标题对齐。

显式排除：既有 60 条平台路由的 path/name/component 改动（门户链决策 #6 继续成立）；`menu:*` 权限键、`MENU_PERMISSION_MAP` 键集与后端 `sys_permission` 存量改动（决策快照 #4 权限键零改动）；任何页面内部结构（tab/列表/表单）改动（决策快照 #10 壳为界）；文件级「生效范围」列与知识库详情 8 tab 收纳（决策快照 #12 非目标）；工作空间切换（决策快照 #8 非目标）；孤儿路由 `/knowledge-review/*`、`/robot-operation/*` 挂载（决策快照 #3）；演示工作台 `/workspace`、`/workspace/custom` 处置（决策快照 #9）；门户层任何改动。

本规格为纯前端特性：唯一消费的后端接口为既有 `GET /notifications/unread-count`（通知未读数，`api/index.ts:2128`），**零 API Contract 新增**（见「数据映射」）。

## 用户任务 {#user-tasks}

- **TASK-101** — 用户在平台内按导航四段到达功能页。入口：单列宽侧栏菜单项。权限：沿用现有菜单权限过滤（无权限项不渲染）。成功结果：跳转对应路由，当前菜单项高亮。失败恢复：直访无权限页面走既有守卫 `/403` 流程；侧栏不出现该菜单项。
- **TASK-102** — 用户查看并处理未读通知。入口：顶栏铃铛。权限：登录即可（铃铛全员可见、不设菜单权限键）。成功结果：进入 `/notification` 通知中心，可查看未读/已读列表、标记已读、删除（既有页面能力）。失败恢复：未读数拉取失败时铃铛无徽标、无报错弹窗（STATE-101），点击仍可进入通知中心。
- **TASK-103** — 用户从平台内阅读操作手册或产品动态。入口：侧栏用户菜单「操作手册」「产品动态」。权限：登录即可（目标为门户公开页）。成功结果：分别到达 `/portal/manual`、`/portal/changelog`。失败恢复：无特殊处理。
- **TASK-104** — 用户查看个人信息或退出登录。入口：内容卡头右上角用户入口（头像 chip，铃铛右侧）下拉。权限：登录态。成功结果：用户信息弹窗展示既有六字段；退出经确认后清会话跳 `/login`。失败恢复：组织名懒加载失败时显示 orgId 原值（既有行为）。
- **TASK-105** — 管理员在角色权限配置页按新分组配置菜单权限。入口：`/admin/account/roles/:id/permissions`。权限：`admin:role`。成功结果：权限树分组标题与导航四段一致，页面节点与权限键不变，存量角色已授权状态不受影响。失败恢复：无特殊处理。

## 页面与路由 {#pages-routes}

- **PAGE-101** — 平台壳（AppLayout + 单列宽侧栏 + 内容卡头），承载全部既有平台路由。入口：登录后任意平台路由。退出路径：侧栏 logo（回门户）、用户菜单退出系统。
- **PAGE-102** — 通知中心，路由 `/notification`（本特性唯一新增路由，AppLayout 子路由族）。入口：顶栏铃铛（TASK-102）。返回路径：侧边栏任一菜单项。页面内部复用 `views/notification/index.vue`，功能零改动。

路由不变量：

- 既有 60 条平台路由的 path、name、component 映射零变化；新增仅 `/notification` 一条。
- `/notification` 不在 `MENU_PERMISSION_MAP` 与 `menu-perm-tree.ts` 注册（守卫对未登记路径放行），角色权限配置页不出现通知节点。
- 门户层（`/portal` 路由族、PortalLayout 顶导航）零改动；登录成功落地 `/home`、面包屑「主页」回链等门户链决策维持不变。

## 元素与交互 {#elements-interaction}

**单列宽侧栏（PAGE-101）**

- 主页项（顶置，段结构之外） — 来源：静态菜单数据；显示：恒显；交互：跳 `/home`，`/home` 激活时高亮。

  - 对话：会话中心 — `/conversation` — 无菜单权限键，登录恒显
  - 构建：应用中心 — `/application` — `menu:application:center`、`app:use`
  - 资源：知识库 — `/knowledge` — `menu:knowledge:list`
  - 资源：我的工具 — `/application/my-tools` — `menu:application:my-tools`
  - 资源：MCP管理 — `/application/mcp-management` — `menu:application:mcp`
  - 资源：技能管理 — `/application/skill-management` — `menu:application:skill`

  - 资源：数据库管理 — `/application/database-management` — `menu:application:database`
  - 资源：模型管理 — `/admin/platform/model-management` — `menu:admin:platform:model`、`admin:system`
  - 资源：提示词 — `/application/prompt-templates` — 沿用现映射
  - 数据分析：知识库分析 — `/operation/kb-analytics` — `menu:operation:kb-analytics`（修订 #15：第四段回侧边栏）
  - 数据分析：检索日志分析 — `/operation/retrieval-analysis` — `menu:operation:retrieval-analysis`

  - 数据分析：模型监控 — `/operation/model-monitor` — `menu:operation:model-monitor`

- 折叠开关（修订 #15） — 来源：静态；显示：侧边栏底部恒显；交互：点击切换图标态（64px，段标题与菜单文字隐藏、菜单项仅图标），状态持久化 localStorage。
- 折叠态悬停浮出（修订 #16） — 触发：折叠态下鼠标悬停侧边栏；可见反馈：右侧浮出 208px 完整菜单（覆盖内容区、带投影，含段标题与文字菜单项）；收回：鼠标离开或点击任一菜单项（点击同时完成跳转）。展开态悬停无浮出层。

## 状态矩阵 {#state-matrix}

- **STATE-101** — 通知未读数状态（铃铛徽标）。触发：进入平台拉取一次；离开 `/notification` 路由时重拉。可见反馈：加载中无徽标；成功 0 → 无徽标、1–99 → 数值、≥100 → `99+`；失败 → 无徽标且无报错弹窗。恢复：下次路由离开 `/notification` 或刷新页面重拉。
- **STATE-102** — 菜单权限过滤。触发：用户角色权限集变化（重新登录/改配角色）。可见反馈：无权限菜单项不渲染；段内全部无权限时段标题不渲染。恢复：授予权限后重新登录可见。

| 页面 | initial / loading | empty | success | error / retry |
|---|---|---|---|---|
| PAGE-101 | 壳与菜单静态直出；未读数拉取中徽标暂缺（STATE-101） | 不适用（菜单为静态数据） | 菜单渲染 + 高亮正确 + 徽标数值正确 | STATE-101（徽标静默缺失）；菜单无异步错误 |
| PAGE-102 | 既有 loading 态（页面内部零改动） | 既有空态（页面内部零改动） | 列表/已读/删除功能同改造前 | 既有错误处理（页面内部零改动） |

不适用项声明：disabled / offline 状态对壳层不适用——菜单为静态数据、无离线场景；PAGE-102 的状态语义由既有页面自身定义，本规格不重述。

## 数据映射 {#data-mapping}

- 通知未读数 ← `GET /notifications/unread-count`（既有端点，`api/index.ts:2128`，前端封装 `getUnreadNotificationCount()`）→ 铃铛徽标数值。响应为数值，无新增字段。
- 用户名 ← userStore 计算属性（`realName` 缺失回退 `username`，`Sidebar.vue:24` 同款）→ 用户区显示。
- 组织名 ← `GET /org/flat` 懒加载映射（既有逻辑平移）→ 用户信息弹窗「所属组织」字段。
- 菜单数据 ← `Sidebar.vue` `allModules` 静态数组按四段重组（前端常量，无运行时接口）。
- 通知列表 ← `GET /notifications` 等既有五个通知端点（`api/index.ts:2124-2140`），由 PAGE-102 既有代码消费，本规格不接新线。
- 除上述既有接口外零后端调用：无 API-*/ERR-* 新引用，无 TBD 字段，API Contract 无新增。

## 响应式与可达性 {#responsive-accessibility}

响应式（平台壳为桌面工具，区别于门户的 768/1024 两档响应式）：

- 视口 <1024px：单列宽侧栏保持常驻，不折叠、不引入汉堡菜单。
- 明示不做：侧栏折叠开关、移动端抽屉导航。

可达性（仅约束壳层新代码，不回溯平台存量页面）：

- 全部菜单项使用语义化可聚焦元素（router-link），可 Tab 到达、Enter 触发；段标题与「数据分析」分组标签为非交互文本，不进入焦点序。
- 焦点顺序 = DOM 顺序（顶置主页 → 四段自上而下 → 底部用户区）。
- 明示不做：skip-link、ARIA 地标增强（与门户决策 #22 同水准）。
