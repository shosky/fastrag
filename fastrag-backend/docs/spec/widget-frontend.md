# Widget — Frontend Spec

> 2026-10-31 由 idd-spec 依据根 CONTEXT.md「Widget 特性决策快照」#1-34 编写，与后端档 [widget.md](./widget.md) 同链配套。
> 快照编号（#N）为本档追溯锚点；数据映射字段级契约待 widget 契约产出后回填。

## 范围 {#scope}

本档覆盖 FastRAG 前端新增的 Widget 能力面，分三块：①**Widget 开发工作台**——资源段新增 `/widget` 页面族（列表页「我的 Widget / 官方模板」双 tab、新建页、编辑页三件套三 tab + 预览面板），照技能三路由惯例；②**应用编辑器绑定面板**——「配置」组新增 Widget 项（第六类绑定 UI，照 SkillConfig 模式）；③**对话窗口卡片**——在会话中心与应用编辑器调试对话两条既有消息流上渲染 Widget 卡片（渲染、交互窗口、回传、历史回看、降级矩阵）。

显式排除：后端协议、校验与存储（widget.md）；可视化拖拽编辑器与代码编辑器依赖（一期 JSON 文本域）；工作流通道渲染；卡片在纯直聊中的展示（不生效）。

## 用户任务 {#user-tasks}

- **TASK-201** — 用户创建一个 Widget（空白新建，或复制官方模板起步）。入口：列表页「新建」按钮 / 官方模板 tab 行内「复制」。权限：登录即可（`widget:*` 预留不强校验）。成功结果：跳转新资产编辑页。失败恢复：接口失败 toast，可重试（STATE-204）。
- **TASK-202** — 用户编辑 Widget 三件套并预览效果。入口：列表页行点击进编辑页。权限：属主（非属主资产不可进，后端拒绝）。成功结果：三档校验通过保存成功，预览同步最新内容。失败恢复：校验失败行级错误落在对应 tab，不弹窗（STATE-205）。
- **TASK-203** — 用户管理自己的 Widget（删除、浏览官方模板）。入口：列表页行操作。权限：属主；官方模板只读。成功结果：删除成功行消失；复制成功进入新资产。失败恢复：被绑定拒删提示先解绑（STATE-204 业务错误形态）。
- **TASK-204** — 应用配置者为应用绑定 Widget。入口：应用编辑器左侧菜单「配置 > Widget」。权限：应用编辑权限（既有 app:edit 门禁）。成功结果：绑定保存（diff 增删 + 启用开关）。失败恢复：上限 10 或校验失败 toast（STATE-204）。
- **TASK-205** — 用户在挂应用的对话中查看智能体输出的 Widget 卡片。入口：应用编辑器调试对话 / 会话中心挂应用的会话。权限：沿用对话通道。成功结果：卡片按快照渲染；同一卡片替换键的后续快照替换旧卡（过程反馈）。失败恢复：坏结构卡内占位不崩整卡（STATE-208）。
- **TASK-206** — 用户在卡片上完成输入并提交回传（或触发跳转/下载）。入口：卡片交互动作。权限：沿用对话通道。成功结果：提交推进新一轮对话（可见回传消息），表单收集值并入回传。失败恢复：回传失败卡片保持可交互可重试（STATE-212）。
- **TASK-207** — 用户回看历史会话中的 Widget 卡片。入口：会话历史消息。权限：沿用会话访问。成功结果：卡片按消息内嵌快照原样渲染，资产已删除仍可渲染。失败恢复：快照缺失/坏结构走占位（STATE-208）。

## 页面与路由 {#pages-routes}

- **PAGE-201** — Widget 列表页，路由 `/widget`（资源段第 9 项菜单「Widget」）。入口：侧边栏资源段；页面族其余页的返回目标。退出路径：侧边栏导航。
- **PAGE-202** — Widget 新建页，路由 `/widget/create`。入口：PAGE-201「新建」。返回路径：保存成功或取消回 PAGE-201。
- **PAGE-203** — Widget 编辑页，路由 `/widget/:id`。入口：PAGE-201 行点击（含官方模板复制成功后跳转）。返回路径：PAGE-201。
- **PAGE-204** — 应用编辑器 Widget 绑定面板——非独立路由，挂在应用编辑器「配置」菜单组 `{key:'widget'}` 下（右侧区域切换渲染），与五兄弟配置面板同位。
- **PAGE-205** — 对话窗口 Widget 卡片渲染面——非新增路由，是会话中心消息流与应用编辑器调试对话消息流上共用的卡片渲染区域；两处走同一渲染组件与同一状态语义。

路由不变量：仅新增三条 `/widget` 路由（照技能路由结构），既有 60+ 条平台路由零改动；`/widget` 不注册菜单权限键与权限树（与沙箱配置/提示词模板同待遇，守卫放行）。

## 元素与交互 {#elements-interaction}

**PAGE-201 列表页**

- 双 tab「我的 Widget / 官方模板」— 来源：静态；显示：恒显；交互：切换过滤（官方 = 内置行视图）。
- 资产行（名称、描述、图标、更新时间）— 来源：资产列表接口；显示：按 tab 过滤；交互：行点击进编辑页（官方 tab 行点击仅查看态进编辑页）。
- 「新建」按钮 — 来源：静态；显示：我的 tab 恒显；交互：跳 PAGE-202。
- 行操作（编辑 / 删除）— 来源：静态；显示：我的 tab 行内；交互：编辑跳 PAGE-203；删除弹确认框，确认后调删除接口，被绑定拒删时 toast 业务错误文案（提示先解绑）。
- 行操作「复制」— 来源：静态；显示：仅官方 tab 行内；交互：调复制接口，成功跳转新资产编辑页。
- 空态引导（我的 tab）— 显示：列表为空；交互：「新建」与「去官方模板复制」双按钮。

**PAGE-202 新建页**

- 基础信息表单（名称必填、描述、图标）— 来源：静态表单；交互：输入。
- 三件套初始内容 — 来源：前端内置最小合法骨架示例（模板/数据结构/默认值各一份可运行示例），可清空改写；交互：随表单一并提交。
- 「保存」/「取消」— 交互：保存走后端三档校验，通过后跳 PAGE-203；取消回 PAGE-201 不留存。

**PAGE-203 编辑页**

- 基础信息区（名称/描述/图标，可编辑）— 交互：随保存一并提交。
- 三 tab「模板 / 数据结构 / 默认值」— 来源：资产三件套；交互：tab 切换；每 tab 一个 JSON 文本域 + 「格式化」按钮（本地格式化，不调接口）。
- 行级错误区 — 来源：保存校验业务错误的逐项行级信息；显示：仅保存失败时，错误落在对应 tab 内，不弹窗；交互：点击错误项聚焦对应 tab。
- 预览面板 — 来源：默认值 JSON 填充模板的静态渲染（复用对话卡片渲染组件）；显示：恒显于编辑区一侧；交互：内容变更后手动「刷新预览」重新渲染；预览中 `sys.submit` 类动作禁用并提示「预览中不可提交，请在应用对话中调试」（STATE-206）。
- 「保存」按钮 — 交互：提交后端三档校验；成功 toast + 内容即时生效提示。

**PAGE-204 绑定面板**

- 候选资产卡片列表（勾选式，仅自建资产）— 来源：候选接口（属主可见）；显示：全部候选；交互：checkbox 勾选。
- 每勾选项「启用」开关 — 来源：绑定状态；显示：已勾选项；交互：切换 per-binding enabled。
- 「保存」按钮 — 交互：与现绑定 diff 增删（照 SkillConfig 模式）；上限 10 的业务错误 toast 提示。

**PAGE-205 卡片渲染面（两处消息流共用）**

- 卡片容器（含状态文本区）— 来源：卡片快照（标识/替换键/名称/模板/数据）；显示：消息流内工具结果位置；交互：无（容器）。
- 组件树渲染 — 来源：快照模板 + 数据（默认值先填充、数据覆盖的合并结果）；显示：递归渲染白名单组件；交互：按组件语义（表单控件可输入、列表项可点）。
- 交互动作按钮 — 来源：快照动作配置（跳转/下载/提交三类型）；显示：动作配置存在时；交互：跳转新窗打开、下载触发下载、提交触发回传（TASK-206）。
- 调用中占位 — 来源：工具调用 calling 态；显示：该工具 chip 隐藏或轻量占位（STATE-207）。
- 回传提交按钮态 — 显示：提交点击后 loading 防重复（STATE-211）；失败后恢复可点（STATE-212）。

## 状态矩阵 {#state-matrix}

| 状态 | 触发 | 适用页面 | 可见反馈 | 恢复路径 |
|---|---|---|---|---|
| **STATE-201** 列表加载 | 进入 PAGE-201 拉取数据 | PAGE-201 | 骨架屏 | 自动完成 |
| **STATE-202** 我的空态 | 我的 tab 无资产 | PAGE-201 | 空态插画 + 「新建 / 去官方模板复制」双引导 | 点击引导按钮 |
| **STATE-203** 官方模板空态 | 官方 tab 为空（播种失败才可见） | PAGE-201 | 兜底空态 + 重试 | 重试拉取 |
| **STATE-204** 接口失败 | 任一列表/保存/删除/绑定接口失败 | PAGE-201/202/203/204 | toast 错误文案（业务错误取返回文案）；列表类附重试按钮 | 重试或修正后重存 |
| **STATE-205** 校验失败行级错误 | 保存被三档校验拒绝 | PAGE-202/203 | 行级错误列表落对应 tab，不弹窗，点击错误聚焦 tab | 修正后重存 |
| **STATE-206** 预览态 | 编辑页打开/刷新预览 | PAGE-203 | 默认值填充的静态卡片渲染；提交类动作禁用 + 提示文案 | 进入对话真实调试 |
| **STATE-207** 卡片生成中 | render_widget 工具 calling 态 | PAGE-205 | 该工具 chip 隐藏或轻量占位文案 | 快照到达转正常渲染 |
| **STATE-208** 卡片降级占位 | 未知组件名 / 模板结构坏 / 快照缺失或结构不符 | PAGE-205 | 卡内占位框 + 控制台告警，不崩整卡，不影响正文渲染 | 无（历史数据不可修复） |
| **STATE-209** 卡片可交互 | 卡片位于最新一条助手消息 | PAGE-205 | 动作按钮正常态 | 用户操作 |
| **STATE-210** 卡片置灰 | 其后任何新消息到达（含回传消息） | PAGE-205 | 交互动作置灰禁点；`alwaysEnabled` 动作（跳转/下载）豁免仍可点 | 无（窗口随对话推进关闭） |
| **STATE-211** 回传提交中 | 提交动作点击后 | PAGE-205 | 提交按钮 loading，禁止重复点击 | 成功转下一轮 / 失败转 STATE-212 |
| **STATE-212** 回传失败 | 回传消息流 error 事件 | PAGE-205 | 错误提示；消息序未推进、窗口未关，卡片保持可交互 | 直接重新提交 |

## 响应式与可达性 {#responsive-accessibility}

- 卡片在消息气泡宽度内自适应布局；列表/行布局组件按组件语义收缩；不引入新断点（跟随平台既有断点）。〔快照 #15〕
- 卡片交互元素一律真实 button/input 元素（组件库基于 Element Plus，天然可达）；焦点顺序 = DOM 顺序；交互元素不用裸 div+click。〔快照 #34〕
- 不做 skip-link 与 ARIA 地标增强（门户链口径沿用，仅约束本特性新代码）。〔快照 #34〕
- 工作台三页复用平台内容卡布局；编辑页三 tab + 预览在窄屏下预览折叠到内容下方（768 断点，跟随全仓主流断点档）。〔快照 #2 约束下的常规布局〕

## 测试策略 {#testing}

组件级测试优先（渲染正确性是本前端档的核心风险面）：①前端渲染注册表与组件白名单一致性守护测试（快照 #9/#17 双份常量钉）；②渲染树递归——组件树、`{{var}}` 插值、默认值先/数据覆盖合并次序；③降级矩阵——未知组件、坏结构、缺快照逐项占位（STATE-208）；④交互窗口——消息序判定、置灰、`alwaysEnabled` 豁免（STATE-209/210）；⑤回传——负载组装、loading 防重、失败恢复（STATE-211/212）；⑥绑定面板 diff 与上限提示；⑦编辑页校验错误落 tab 与聚焦。对话流集成用例沿用既有两 composable 测试模式，mock SSE 事件序列。
