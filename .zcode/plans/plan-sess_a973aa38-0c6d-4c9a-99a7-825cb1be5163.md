## 目标
优化知识库详情页「日志管理」Tab（`LogPanel.vue`）的布局与翻页。

## 现状问题
1. **无翻页**：后端 `GET /api/kb/{kbId}/logs` 忽略 page/pageSize，一次性返回全部日志；前端 `LogPanel.vue` 也没有任何分页组件，日志多时页面渲染全部行。
2. **布局**：LogPanel 整体已嵌在详情页白色卡片（`kb-detail__tabs`）内，但筛选栏又套了一层白底圆角样式，白上加白；搜索为客户端过滤，与分页无法共存。
3. 不符合 AGENTS.md 统一分页规范（必须用 `usePagination` + 统一 el-pagination 模板）。

## 方案：前后端完整实现服务端分页（符合 AGENTS.md「大部分列表用服务端分页」+ 现有 `PageResult`/`selectPage` 惯例）

### 后端 `fastrag-publish` 模块（3 个文件）
1. **`LogService.java`**：`listLogs(kbId, category)` 改为 `PageResult<KbLog> listLogs(kbId, category, keyword, page, pageSize)`；新增 `Map<String, Long> countByCategory(kbId)`（仅 LogController 调用此方法，改动安全）。
2. **`LogServiceImpl.java`**：
   - `listLogs`：`LambdaQueryWrapper` 增加 category 等值、keyword 对 target/detail/operator 的 LIKE 过滤，`orderByDesc(timestamp)`，`selectPage(new Page<>(page, pageSize), w)` → `PageResult.of(records, total, page, pageSize)`。
   - `countByCategory`：4 次 `selectCount`（total + operation/retrieval/publish，共 3 个枚举值），返回 `{total, operation, retrieval, publish}`。
3. **`LogController.java`**：
   - `GET /api/kb/{kbId}/logs` 增加 `keyword`、`page`(默认1)、`pageSize`(默认10) 参数，返回 `PageResult`。
   - 新增 `GET /api/kb/{kbId}/logs/stats` 返回分类计数（供筛选按钮的「全部 (N)」等统计显示，分页后前端无法自行计算）。

### 前端（2 个文件）
4. **`src/api/index.ts`**：`getKbLogs` 参数类型加 `keyword`；新增 `getKbLogStats(kbId)`。
5. **`src/views/knowledge/detail/components/LogPanel.vue`**：
   - 使用共享 composable `usePagination(10)`（不再手写 ref），`currentPage`/`pageSize`/`total` 来自接口。
   - `refresh()`：`Promise.all` 并行拉取日志分页列表 + 分类统计。
   - 搜索：300ms 防抖 watch `searchKeyword` → 重置到第一页重新请求（服务端搜索）。
   - `handleCurrentChange` / `handleSizeChange` 按 AGENTS.md 约定：更新状态后重新拉取。
   - **统一分页模板**：`<div class="log-panel__pagination"><el-pagination v-model:current-page v-model:page-size :total :page-sizes="[10,20,50,100]" layout="total, sizes, prev, pager, next, jumper" @current-change @size-change /></div>`，SCSS 严格按规范：`display:flex; justify-content:flex-end; margin-top:16px;`。
   - 表格 `:data="logs"` 只渲染当前页，移除客户端 `filteredLogs`。
   - **布局优化**：筛选栏去掉多余的「白底圆角」（面板已处于白色卡片内），改为透明 flex 行：左侧分类 radio（计数来自 stats），右侧搜索框 + 刷新按钮；表格保持 stripe/small；空数据 `el-empty` 条件不变。

### 验证
- 后端：`mvn -q compile -pl fastrag-modules/fastrag-publish -am`（在 fastrag-backend 目录）确认编译通过。
- 前端：`vue-tsc` 或项目现有 type-check 脚本确认类型无误。

注意：改完需重启后端服务才能生效（前端 dev server 热更新）。
