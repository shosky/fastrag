
# 问答对 Excel 导入功能实现计划

## 决策汇总（来自 grilling 会话）

| 决策 | 结果 |
|------|------|
| 导入模式 | **同步 REST**（上传后阻塞等待，后端直接返回完整结果） |
| 重复处理 | 默认**跳过**，导入对话框提供「覆盖已存在的问答对」开关 |
| 重复检测 | **归一化后精确匹配**（trim + 压缩空白 + 统一全角/半角） |
| 错误处理 | **部分成功** — 合法行入库，非法行记录到错误报告 |
| 结果展示 | **结果对话框** — 三个标签页：成功列表 / 跳过列表（含原因） / 失败列表（含行号+错误） |
| `source` 字段 | **固定为 `manual`**，Excel 模板中不包含此列 |
| API 路径 | **专用端点** `POST /api/kb/{kbId}/qa-pairs/import` |
| 条数上限 | **10,000 条**，超出返回明确错误建议分批 |
| `fileId` 关联 | **固定为 null**，不关联文件 |

### 3. 新增工具类：`ExcelQaPairImporter.java`

**路径：** `fastrag-knowledge/.../util/ExcelQaPairImporter.java`

职责：纯 POI Excel 解析，不涉及数据库操作。

- `parse(MultipartFile file, boolean overwrite)` → `QaImportResult`
- 支持 `.xlsx`（`XSSFWorkbook`）和 `.xls`（`HSSFWorkbook`）
- 读取**第一个可见 Sheet**，第 1 行为表头
- 列映射（大小写不敏感，模糊匹配列名）：

| Excel 列名（支持变体） | 必填 | 说明 |
|---|---|---|
| `问题` / `question` | ✅ | 去空白后非空 |
| `答案` / `answer` | ✅ | 允许为空（但建议填写） |
| `分类` / `category` | ❌ | 存入前暂不使用（QaPanel 字段未持久化） |
| `关键词` / `keywords` | ❌ | 同上 |
| `优先级` / `priority` | ❌ | 整数 1–10，默认 5 |
| `状态` / `status` | ❌ | 仅接受 `draft` / `confirmed`，默认 `draft` |
| `生效时间` / `effectiveTime` | ❌ | 暂不使用 |
| `失效时间` / `expireTime` | ❌ | 暂不使用 |

- 行校验规则：
  - `question` 去空白后为空 → 失败（`问题不能为空`）
  - 超过 10,000 行 → 直接抛 `BusinessException`（`Excel 行数超过 10000 条上限，请分批导入`）
  - 日期/优先级格式非法 → 失败（记录具体原因）
- 重复检测：从数据库预加载该 `kbId` 下所有 question，存入 `Set<String>`（归一化后），逐行检查。`overwrite=true` 时查询已有记录用于后续更新。

### 5. 修改 `QaPairServiceImpl.java` — 实现 importFromXlsx

```java
@Override
public QaImportResult importFromXlsx(String kbId, MultipartFile file, boolean overwrite) {
    // 1. 用 ExcelQaPairImporter 解析文件
    QaImportResult result = ExcelQaPairImporter.parse(file, overwrite);

    // 2. 收集需要插入和更新的实体
    List<KbQaPair> toInsert = new ArrayList<>();
    List<KbQaPair> toUpdate = new ArrayList<>();

    for (ImportRowResult row : result.getDetails()) {
        if (!"success".equals(row.getStatus()) && !"skipped".equals(row.getStatus())) continue;
        // ... 构建实体，区分 insert/update
    }

    // 3. 事务内批量写入
    transactionTemplate.executeWithoutResult(status -> {
        for (KbQaPair e : toInsert)  mapper.insert(e);
        for (KbQaPair e : toUpdate)  mapper.updateById(e);
    });

    // 4. 更新 counts
    result.setSuccessCount(toInsert.size() + toUpdate.size());
    result.setSkipCount(result.getDetails().stream().filter(r -> "skipped".equals(r.getStatus())).count());
    result.setFailCount(result.getDetails().stream().filter(r -> "failed".equals(r.getStatus())).count());

    return result;
}
```

**依赖注入：** 在 `QaPairServiceImpl` 中注入 `TransactionTemplate` 和 `LogService`（后者用于审计日志，参考现有 `@Loggable` 用法）。

### 6. 修改 `QaPairController.java` — 新增 import 端点

```java
@KbAuth(KBRole.editor)
@Loggable(category = LogCategory.operation, action = ActionType.qa_pair_created,
          detail = "批量导入QA对")
@PostMapping(value = "/import", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
public ApiResponse<QaImportResult> importXlsx(
        @PathVariable String kbId,
        @RequestParam("file") MultipartFile file,
        @RequestParam(defaultValue = "false") boolean overwrite) {
    return ApiResponse.success(svc.importFromXlsx(kbId, file, overwrite));
}
```

## 二、前端实现（2 个新文件 + 2 个修改）

### 1. 修改 `src/api/index.ts` — 新增 2 个 API 函数

```typescript
// 下载问答对导入模板
export async function downloadQaImportTemplate() {
  return request.get('/kb/qa-pairs/import-template', { responseType: 'blob' })
}

// 导入问答对 Excel
export async function importQaPairs(kbId: string, file: File, overwrite: boolean) {
  const formData = new FormData()
  formData.append('file', file)
  formData.append('overwrite', String(overwrite))
  return request.post(`/kb/${kbId}/qa-pairs/import`, formData, {
    headers: { 'Content-Type': 'multipart/form-data' }
  })
}
```

## 四、异常场景处理

| 场景 | 处理方式 |
|------|----------|
| 上传非 Excel 文件 | 后端检查扩展名/Content-Type，返回 400 |
| Excel 加密/损坏 | catch `EncryptedDocumentException`，返回 400 |
| 超过 10,000 行 | 解析阶段直接抛 `BusinessException` |
| 必填列缺失 | 解析时检查列名映射，找不到 `question`/`answer` 列则抛 400 |
| 数据库写入失败 | `TransactionTemplate` 自动回滚全部插入，报告全失败 |
| 超大文件（>10MB） | 前端 `before-upload` 校验 `file.size / 1024 / 1024 > 10`，提示「文件大小不能超过 10MB」 |
| 并发重复写入 | 重复检测基于**导入前快照**，并发场景下极低概率产生重复；如需严格保证，需加唯一索引 `(kb_id, question)`（独立于本次功能） |
