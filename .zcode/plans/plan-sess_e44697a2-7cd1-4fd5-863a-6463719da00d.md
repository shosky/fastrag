### 2. 分册一：`docs/design/rag-chunk-recall-enhance.md`（问题1：分片切断召回增强）
- 现状盘点：overlap(100) / structure_aware / parent_child / window / titlePrefix / Multi-Query / 多路召回 RRF 已实现；但默认策略 rule_fixed+concat 未串联最优组合；前端请求路径（AppServiceImpl.retrieveContext、RetrievalServiceImpl）默认配置未触发
- 差距：默认配置未启用强上下文机制；parent_child 组装在默认路由不可达；缺少"召回小片→返回大片"在默认链路的自动降级
- 目标方案：
  - P0：检索链路默认启用上下文完整性（contextAssemblyStrategy 自动降级链 concat→parent_chunk→window）
  - P0：多认知线索融合（标题/条款编号检索补充向量召回）
  - P1：parent_child 建索引 + parent_chunk 组装的默认开启路径与配置
  - P2：语义分块 / RAPTOR 摘要树（远期）
- 改造点清单：RetrievalServiceImpl、ParentChunkAssembler、RetrievalRequest、AppServiceImpl、前端 RetrievalSettingPanel
- 评测闭环：复用已建 migration-20260818-chunk-recall-enhance.sql 的 cross_boundary 题 + context_completeness 指标，定义验收标准

### 3. 分册二：`docs/design/rag-broad-query-enhance.md`（问题2：宽泛问题/地域时间层级检索）
- 现状盘点：混合检索、同义词、Multi-Query、图谱扩展（默认开）、多路召回、App 多KB串行检索已实现；但 **无元数据字段、无时间排序、无按层级过滤**；App 多KB检索无全局融合
- 差距：KbFile/KbChunk 无 region/publish_date/doc_level；RetrievalRequest 无 metadataFilter/sortBy；AppServiceImpl.retrieveContext 逐KB topK 截断无全局 RRF
- 目标方案（LLM+规则自动提取元数据）：
  - P0：KbFile/KbChunk 增加元数据字段（migration SQL）；入库时 LLM+规则抽取（地域/发文日期/发文层级），行政区划库+正则辅助，抽取结果可人工校订
  - P0：检索端元数据过滤 + 时间倒序排序（RetrievalRequest 增加 metadataFilter/sortBy；向量 Milvus filter expr + 全文/回退 SQL WHERE）
  - P1：App 多KB联合检索全局 RRF 融合 + 全局 sortBy；查询意图自动解析地域（"湖南"→region=湖南）
  - P1：前端检索配置面板增加过滤/排序入口（不改变页面风格规范）
- 改造点清单：KbFile/KbChunk 实体、migration SQL、元数据抽取服务（新）、RetrievalServiceImpl、AppServiceImpl、RetrievalRequest、前端类型与面板
- 评测：基准题集"地域+时间+层级"覆盖评估，验收标准含时间倒序正确性

### 4. 分册三：`docs/design/rag-pdf-table-image-extraction.md`（问题3：PDF表格图片提取）
- 现状盘点：PDFBox 文本流（无表格结构）、OCR 兜底（<50字符）、图片6层过滤+MinIO+并发OCR、图片分片按页归并、Atomic Unit 表格保护、DOCX/XLSX 已有结构化表格（POI）
- 差距：PDF 表格无结构化提取（对比 DOCX/XLSX）；过滤阈值硬编码不可配；图片与文本位置关联弱；表格图片 OCR 无结构保持
- 目标方案（Java 轻量表格识别）：
  - P0：parsePdf 内实现"文本坐标聚类表格检测"（复用 PDFTextStripper TextPosition + PDFRenderer 行线检测），输出 Markdown 表格；既有表格 Atomic Unit 保护自然生效
  - P1：表格识别参数化（tableMode 对 PDF 生效；过滤阈值进入 ParseStrategyConfig/系统配置）
  - P1：表格图片（TableImage）特殊处理：表格图像→结构OCR/表格还原，关联到上下文分片
  - P2：多模态 LLM 复杂表格兜底（远期，标注利弊）
- 改造点清单：DocumentParserImpl.parsePdf、MediaExtractor、ParseStrategyConfig、ChunkingServiceImpl 表格单元处理、新增 TableDetector（新）
- 评测：表格还原对照样例集（正确行列数、表头保留、多页表），验收标准
