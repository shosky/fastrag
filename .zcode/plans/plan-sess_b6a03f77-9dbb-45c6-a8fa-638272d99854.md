
## 目录行增强：重命名/删除操作、类型过滤器、时间列显示

### 概述
为文件列表中的目录行增加三个功能：
1. 目录行的操作列增加"重命名"和"删除"下拉菜单
2. 查询条件区域增加"类型"过滤器（全部/文件夹/文件）
3. 目录行显示创建时间和更新时间（需全栈增加文件夹时间戳字段）

---

### 第 1 部分：后端 — 为文件夹增加 `createdAt` / `updatedAt` 时间戳

#### 1.1 数据库 Schema（`init-scripts/schema.sql`）
```sql
ALTER TABLE kb_folder
  ADD COLUMN created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  ADD COLUMN updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP;
```
对 `schema-h2.sql` 也同步增加 `kb_folder` 表定义（含时间戳列）。

#### 1.2 实体 `KbFolder.java`
增加两个字段，复用项目已有的 MyBatis-Plus `MetaObjectHandler` 自动填充机制：
```java
@TableField(fill = FieldFill.INSERT)
private LocalDateTime createdAt;

@TableField(fill = FieldFill.INSERT_UPDATE)
private LocalDateTime updatedAt;
```

#### 1.3 DTO `FolderNodeDto.java`
增加两个字段：
```java
private String createdAt;
private String updatedAt;
```

#### 1.4 Service `FolderServiceImpl.java` — `buildTree` 方法
映射 `createdAt` 和 `updatedAt` 到 DTO：
```java
dto.setCreatedAt(folder.getCreatedAt() != null ? folder.getCreatedAt().toString() : null);
dto.setUpdatedAt(folder.getUpdatedAt() != null ? folder.getUpdatedAt().toString() : null);
```

### 第 3 部分：`FileTable.vue` — 三项前端改动

#### 3.1 增加 `FolderRow` 的时间字段和新的 emits
```typescript
interface FolderRow {
  isFolder: true
  id: string
  label: string
  createdAt?: string
  updatedAt?: string
}

// 新增 emits
(e: 'renameFolder', folderId: string, label: string): void
(e: 'deleteFolder', folderId: string): void
```

#### 3.2 `folderRows` computed — 映射时间字段
```typescript
const folderRows = computed<FolderRow[]>(() => {
  return (props.folders || []).map((f) => ({
    isFolder: true as const,
    id: f.id,
    label: f.label,
    createdAt: f.createdAt,
    updatedAt: f.updatedAt,
  }))
})
```

#### 3.3 新增类型过滤器 `typeFilter`
```typescript
const typeFilter = ref<'all' | 'folder' | 'file'>('all')
const typeOptions = [
  { label: '全部', value: 'all' },
  { label: '文件夹', value: 'folder' },
  { label: '文件', value: 'file' },
]
```

修改 `displayRows` 逻辑：
```typescript
const displayRows = computed(() => {
  const showFolders = typeFilter.value !== 'file'
  const showFiles = typeFilter.value !== 'folder'
  return [
    ...(showFolders ? folderRows.value : []),
    ...(showFiles ? pagedFiles.value : []),
  ]
})
```

在工具栏中增加类型筛选下拉（在状态过滤器之后）。

#### 3.4 操作列 — 目录行显示下拉菜单
将 `v-if="!row.isFolder"` 改为分支逻辑：
```html
<el-table-column label="操作" width="80" align="center" fixed="right">
  <template #default="{ row }">
    <!-- 文件夹行：简化操作菜单 -->
    <template v-if="row.isFolder">
      <el-dropdown trigger="hover" @command="(cmd: string) => handleFolderCommand(cmd, row as FolderRow)">
        <el-button :icon="MoreFilled" link class="file-table__more-btn" />
        <template #dropdown>
          <el-dropdown-menu>
            <el-dropdown-item command="rename" :icon="Edit">重命名</el-dropdown-item>
            <el-dropdown-item command="delete" :icon="Delete" divided>
              <span class="file-table__delete-text">删除</span>
            </el-dropdown-item>
          </el-dropdown-menu>
        </template>
      </el-dropdown>
    </template>
    <!-- 文件行：现有逻辑不变 -->
    <template v-else>
      ...existing dropdown...
    </template>
  </template>
</el-table-column>
```

新增 `handleFolderCommand`：
```typescript
function handleFolderCommand(cmd: string, folder: FolderRow) {
  if (cmd === 'rename') emit('renameFolder', folder.id, folder.label)
  else if (cmd === 'delete') emit('deleteFolder', folder.id)
}
```

#### 3.5 时间列 — 目录行显示实际时间
上传时间列和更新时间列：
```html
<span v-if="row.isFolder">{{ (row as FolderRow).createdAt || '-' }}</span>
<span v-else>{{ row.createdAt }}</span>
```

#### 3.6 排序方法 — 兼容 FolderRow
为排序回调增加空值保护：
```typescript
:sort-method="(a: any, b: any) => {
  const va = a.isFolder ? '' : (a.createdAt || '')
  const vb = b.isFolder ? '' : (b.createdAt || '')
  return va.localeCompare(vb)
}"
```
