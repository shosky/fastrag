## 3. State Ownership

| STATE | 所有者 | 说明 |
|---|---|---|
| 基准列表 | server → useBenchmark 实例（面板各自一份） | create/generate 本地 unshift |
| 评估列表/latest | server → useEvaluation（latest = evaluations[0]） | — |
| 轮询集 | client（runningEvalIds Set + 单定时器 3s） | 终态删 id+清缓存+刷新 |
| 详情缓存 | client（localStorage TTL 30min） | 终态主动删缓存 |
| preselect | 父组件（index.vue）→ props 单向 | openStartDialog 消费后 emit 清空 |
| 配置表单 | form | 默认名时间戳生成 |
| 前端分页 ×4 | usePagination | watch 长度重置页码 |

## 4. Data Flow

```
useBenchmark(kbId): load/syncOptions/create(本地插入)/generate/remove(本地过滤)/detail 转发
useEvaluation(kbId): load(.list||数组 容错)/start(缓存+刷新)/remove(清缓存)/
                    getCachedDetail(TTL 30min)/startPolling(3s 单定时器遍历)
跨 Tab: emit(benchmark.id) → 父 preselect+切 Tab → openStartDialog 消费
运行中同步: watch(evaluations) → 弹窗中评估到终态 → fetchEvaluationDetail 全量
           （列表无逐题 results）→ 失败降级列表行拼（Recall 置 0）
命名转换点: syncOptions（`${name} (N 个问题)`）；分数圆圈 `overallScore*100 toFixed(1)`；
          仅查看错误 `filter(r => !r.isCorrect)`（number 0/1 依赖 falsy）
```

## 5. Visual System
