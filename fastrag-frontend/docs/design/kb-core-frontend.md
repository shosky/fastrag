## 3. State Ownership

| STATE | 所有者 | 说明 |
|---|---|---|
| KB 列表数据 + 筛选链 | server → 页内 ref；筛选/分页全前端 | tab/keyword 变化重置 page（index.vue:107-108） |
| 表单模型 | form（el-form model，四 Tab 共享一个 model） | KnowledgeBaseForm 类型 |
| shareType / 已选部门/人员 | form（弹窗互斥逻辑在页内） | 切换清空另一类型 |
| ACL 编辑集 | form（仅 edit 保存时提交） | 创建模式不落库（INFERRED-2） |
| 分类列表/表单 | server + 页内 ref / dialog form | 普通用户 orgId 强制本组织 |
| 首页聚合 | server（getHomeData 一次性） | 无局部刷新 |
| 路由 :id | URL | edit 模式数据键 |

## 4. Data Flow

```
api（kb/categories/acls 支撑组）→ request 解包
  → 表单体具名转换：form.vue
     · normalizeAdvanced 无涉及；本域关键转换 =
       shareType↔permission 映射（:511-518）
       ACL 构造器（:520-565，唯一 ACL 写入点）
       hydrateShareFromAcl 回填（:321-349，唯一 ACL→表单点）
       customAttrs 规整（:571-584）
  → 组件：卡片/表格/四 Tab
```

规则：ACL 读写只许经上述两个具名点；列表筛选链集中在 loadAndFilter 一处（index.vue:58-111）。

## 5. Visual System

- 列表为**卡片网格**（非表格）——全站唯一卡片列表形态；分类色点 8 预设色（COLORS 常量）。
- form.vue 右侧栏双形态（创建进度 4 步 / 编辑元数据 + 危险区红钮）。
- token/公共类沿用 global.scss；断点无（全站一致）。
