# 评测与基准 — Frontend Spec（benchmark-evaluation-frontend）

> 由 /idd-spec 于 2026-09-21 生成（onboard 特征化模式）。Parent Trace ← `docs/feature-map.md` 特性 11 证据包；术语 ← `CONTEXT.md`（图谱评估）。

## 1. Scope

覆盖评估 Tab 双子面板（评估基准/评估结果）与两 composable。**排除**：评测执行与指标计算（后端 @Async）；图谱 chunkCount 数据源（knowledge-graph 链）。

## 2. User Tasks

- **TASK-001 管理评估基准** — 卡片网格（名称/描述/条件标签 Gold Chunks·Gold Answer·自动生成/问题数）：上传（名称+JSONL 文件；**文件不上传不解析**——仅按文件大小粗估 questionCount `min(10,max(5,size/500))` 随表单提交，createBenchmarkApi 只 POST `{name,description,questionCount}`——「上传」语义名实不符，INFERRED-1）；LLM 自动生成（名称自动 `Test-YYYY-MM-DD-xxxx`/构建方式 vector|graph 两卡（graph 卡展示图谱 chunkCount）/LLM 模型必选/参数 questionCount 1-100、candidateChunkCount 1-10、concurrency 1-20、graph 模式 expandChunkCount 1-10）（EvaluationBenchmarkPanel:216-478 ‹CERTAIN›）。
- **TASK-002 查看基准详情** — 问题表 4 列（#/问题/Gold Chunks/Gold Answer）+ 前端分页 10/20/50 + 不换行开关；**Gold tag 恒显示「有」不按实际判断**（:490-517,494-495 ‹CERTAIN›，INFERRED-2）。
- **TASK-003 删除基准/记录** — confirm；**catch 静默且注释「用户取消」——取消与删除失败共用分支，失败无提示**（:175-187; RagEvaluationPanel:242-254 ‹CERTAIN›，INFERRED-3）。
- **TASK-004 发起评估（跨 Tab 联动）** — 基准卡「发起评估」→ emit(benchmark.id) → 父置 preselectBenchmark + 切结果 Tab → 打开配置对话框时消费预选（openStartDialog 内；onMounted 自动弹窗注释与实际不符——非 lazy Tab 不重新 mount）（EvaluationBenchmarkPanel:189-192; index.vue:223-228,328-341; RagEvaluationPanel:106-109,283-287 ‹CERTAIN›，INFERRED-4）。
- **TASK-005 配置并启动评估** — 配置对话框：名称（默认 `eval-YYYYMMDD-xxxxxx`）/基准下拉（`${name} (N 个问题)`）/答案生成模型/评判模型（clearable「留空则用规则评判」）/检索模式 hybrid|vector|fulltext/向量化模型/Rerank 开关+条件模型；流程说明 tip：overallScore = Recall@10×0.7 + AnswerAccuracy×0.3 → `runEvaluationApi` → 缓存 detail 至 localStorage（TTL 30min，key `fastrag_evaluation_detail_cache`）+ 轮询（:413-516; useEvaluation:11,56-95 ‹CERTAIN›）。
- **TASK-006 轮询与结果同步** — POLL_INTERVAL 3s；`runningEvalIds` Set 单定时器遍历 fetchEvaluationStatus，到 completed|failed 删 id、清缓存、load() 刷新；unmount stopPolling；轮询异常整体静默（useEvaluation:97-135,123-125 ‹CERTAIN›）。
- **TASK-007 查看结果** — 最后一次评估卡（分数圆圈 1 位小数/状态 tag/Recall@10/耗时/数据量 completedCount/dataCount/完成率）+ 历史表（查看/删除）；详情弹窗：指标汇总（Recall@1/3/5/10+答案准确率%）+ 结果表（问题/生成答案/检索指标/isCorrect tag+judgeReason）+「仅查看错误」过滤 + 分页；**运行中弹窗随列表状态到终态自动拉全量详情**（列表接口无逐题 results），详情 API 失败降级用列表行拼（Recall@1/3/5=0）（RagEvaluationPanel:173-240,297-410,518-583 ‹CERTAIN›）。
- **TASK-008 刷新** — 两面板各自 load + toast；**两面板 benchmark 状态不共享**（useBenchmark(kbId) 每次调用独立 refs），评估面板靠自身刷新同步（useBenchmark:15-16 ‹CERTAIN›，INFERRED-5）。

## 3. Pages & Routes

无独立路由：详情 Tab「evaluation」内嵌 border-card 双子 Tab（评估基准/评估结果）（index.vue:321-343）。

## 4. Elements & Interaction

跨 Tab 联动（preselect 消费点仅在 openStartDialog）；「仅查看错误」= `results.filter(r => !r.isCorrect)`（isCorrect 为 number 0/1，依赖 0 falsy）；历史表/详情/问题表均 usePagination 前端分页 + watch 数据长度重置页码。
